Activer l’import Google Play

La page YiDream est hébergée sur GitHub Pages. Pour télécharger une APK, un petit service doit tourner sur l’ordinateur qui utilise la console. Il reste accessible uniquement sur cet ordinateur.

Ce guide utilise le projet ouvert alltechdev/gplay-apk-downloader (licence GPL-3.0). Il ne copie pas son code dans YiDream.

1 · Installer les prérequis sur Mac

  1. Installe Python 3 et Java 17.
  2. Dans Android Studio → SDK Manager → SDK Tools, installe « Android SDK Build-Tools » pour avoir apksigner.
  3. Dans Terminal, ajoute Java 17 et le dossier Build-Tools au chemin. Remplace XX.X.X par le numéro du dossier installé :
export PATH="$(brew --prefix openjdk@17)/bin:$PATH"
export PATH="$PATH:$HOME/Library/Android/sdk/build-tools/XX.X.X"

2 · Télécharger et préparer le service

git clone --depth 1 https://github.com/alltechdev/gplay-apk-downloader.git
cd gplay-apk-downloader
./setup.sh

Si la préparation indique qu’une dépendance manque, installe-la puis relance ./setup.sh.

3 · Démarrer le service en local

Dans le même Terminal, lance :

source .venv/bin/activate
CORS_ORIGINS=https://qinfrance.github.io HOST=127.0.0.1 PORT=5000 python3 server.py

Laisse cette fenêtre Terminal ouverte pendant l’import. L’adresse est limitée à ton ordinateur.

4 · Connecter le compte Google Play

Ouvre le téléchargeur local, puis connecte un compte Google dédié si le service le demande. Le projet recommande de ne pas utiliser ton compte Google principal.

5 · Importer dans YiDream

  1. Retourne dans la boutique MDM.
  2. Colle le lien Google Play de l’application et clique « Lire la fiche Play ».
  3. Clique « Télécharger l’APK », vérifie le paquet, la version et l’empreinte, puis « Publier dans la boutique ».
Attention : si une application est distribuée en plusieurs APK, le téléchargeur peut les fusionner et signer le résultat avec une clé de débogage. Certaines applications peuvent alors refuser l’installation, la connexion ou les mises à jour. Vérifie l’application avant de la déployer. Les applications payantes ne sont pas prises en charge par le projet.

À propos des données

Le service fonctionne sur ton ordinateur. Les identifiants de téléchargement Google sont conservés localement par ce projet tiers. Les APK importées ensuite sont envoyées au stockage YiDream configuré pour ton compte administrateur.
